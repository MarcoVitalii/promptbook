# How to move, back up and share a show

A show is one `.zip` file. Whoever has the file has the show: text, cues, ink, boards, settings and the whole history.

## Know where the show is

Look beside the title.

| It says | The show is |
|---|---|
| **Saved** and a time | In its file on disk, up to date |
| **Saving soon**, **Saving…** | About to be |
| **Not on disk** | Only inside this browser |
| **Save failed** | Not saved; a message says why |

A show that is only in the browser is lost if the browser's data is cleared. Put it in a file: **☰** → **Save as show file…**.

## Back it up

Copy the `.zip`. That is a complete backup.

A habit that costs nothing: after each rehearsal, when you have saved the revision, copy the file to a second place (a USB key, a synced folder) with the date in its name.

The history inside the file protects against a bad change. It does not protect against losing the file. Only a copy does.

## Move it to another machine

1. Copy the `.zip` to the other machine.
2. Open `promptbook.html` there (the same release or a newer one) and press **Open show file…**.

Night mode, zoom and the view switches do not travel: they belong to each browser.

## Keep it in a synced folder

A show file can live in a folder that Dropbox, OneDrive or similar keeps in step. Then:

- **Only one person has it open for editing.** There is no merging of two people's changes.
- If the file is replaced from outside while you have it open and nothing of yours is unsaved, it is reloaded. If you do have unsaved changes, a banner asks: **Keep mine** or **Load that version**. Nothing is overwritten until you answer.

## Give the author the text

The author does not need the tool.

- **To read:** print "Script pages only" to PDF, or send a cast file.
- **To edit:** **☰** → **Edit whole script…**, copy everything, send it as a text file. How to take it back: [Take in a rewrite](04-take-in-a-rewrite.md).

The script is also inside the zip, as `script.md`: any zip tool can take it out and any text editor can read it.

## Give someone the whole show

Send the `.zip`. They open it with `promptbook.html`. Agree who holds the pen: two copies edited at once become two shows.

## From a browser that cannot save files

In a browser other than Chrome or Edge the show stays inside the browser. To get it out: **Export backup** (in the banner, or in the Menu) writes one `.promptbook.json` file with everything except the history. In Chrome or Edge: **Import a backup file…** on the start screen, then **Save as show file…**.

## If something is off

- **"This show comes from a newer release."** The file was last saved by a newer `promptbook.html` than the one you opened. It is open, but get the newer tool before changing much.
- **"This show file has parts that cannot be read."** The show opens without them and nothing is saved until you choose. If you have a recent copy, choose **Close the show** and open the copy. Otherwise **Go on without**: the damaged part is kept aside in the file.
- **"damaged zip file".** The file is cut short or broken; it was not touched. Use your copy.
- **The file is getting large.** Every revision adds to it, images above all. It is still one file; copy it less often to slow media.
