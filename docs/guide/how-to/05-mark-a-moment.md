# How to mark a moment, and go back to it

Name the state of the show so you can return to it or compare with it later.

## Before you start

The show must be a file on disk. If the banner says it is only in this browser: **☰** → **Save as show file…** first.

## Save a revision

1. **☰** → **History…**
2. Type a name that will mean something in a month: "Rehearsal 12 October", "Before cutting the prologue", "As printed for the cast".
3. Press **Save revision**.

It joins the list with its date. A revision holds the whole show: text, cues, ink, boards, templates, settings.

Good moments to save one:

- the end of every rehearsal;
- before any large change, and after it;
- whenever pages or a cast file go out (then you know what people have);
- before the first performance.

## See what a revision was

There is no way to look at an old revision without going to it. Two options:

- **Changes** beside it shows how its text differs from now. Often that answers the question.
- **Restore** it, look, and restore your way back (below).

## Go back to a revision

1. **☰** → **History…**
2. Press **Restore** beside the revision.

The show is now as it was then, all of it: the old text, the old cues, the old ink and boards.

Nothing was lost. Before going back, the tool saved what you had as a revision named "Before going to “…”". To return to today, restore that one.

## Bring back only one thing

A restore is all or nothing. To get back a single speech you cut last week:

1. **Restore** the old revision.
2. Double-tap the speech, select its text, copy. Esc.
3. **☰** → **History…** → **Restore** "Before going to “…”".
4. Double-tap the speech before the place, paste the old one on a new line, Ctrl+Enter.

## If something is off

- **"History is kept inside the show file."** The show is not on disk yet. Save it as a show file.
- **"That name is taken."** Revisions cannot share a name; add the date.
- **A wrong name, or a revision you do not want.** They cannot be renamed or deleted in the tool. Save another with the right name; the list is by date.
- **"Part of this history is damaged."** The show itself is untouched and can be saved. The box lists the revisions it can still read. Save a new revision now, and make a copy of the file.

What a revision is, and how it differs from a variant and a lock: [Revisions, variants and locked pages](../explanation/03-revisions-variants-locks.md).
