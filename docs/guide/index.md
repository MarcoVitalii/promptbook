# Using Promptbook

For the stage manager who keeps the book, and for the author whose text keeps changing under it.

A production has one script and many copies of it: the prompt book on the desk, the pages in the actors' hands, the scripts on their phones, the cue sheets of each operator, last week's version that someone still rehearses from. The work of the stage manager is to keep all of them the same show. These pages say how Promptbook helps with that, and where it does not.

They are arranged by what you need at the moment.

## I am new: show me

- [A first show, start to finish](tutorial.md). Forty minutes with the sample scene: a cue, a pen stroke, a revision, a rewrite, a file for the cast, a run in show mode. Nothing of yours is at risk.

In the tool itself, **Guide** in the bottom right corner (or the H key) puts a number on every button and says what each one does.

## Who these pages talk to

**The stage manager** holds the prompt book: one person, one laptop with a pen, one show file. Everything in these pages is done by that person unless it says otherwise.

**The author** (or the director who rewrites) changes the words. The author does not need the tool; they need to know how to hand over a change so that nothing pinned to the old words is lost. That is in [Take in a rewrite](how-to/04-take-in-a-rewrite.md) and [What survives a rewrite](explanation/02-what-survives-a-rewrite.md).

**The actors** get a file and open it on a phone. What they see is in [The script in the actors' hands](explanation/04-the-cast-script.md).

Only one person edits a show at a time. Promptbook has no server and no accounts: a show is a file, and whoever has the file has the show.
