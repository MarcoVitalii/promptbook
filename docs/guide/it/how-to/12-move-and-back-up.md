# Come spostare, salvare in copia e condividere uno spettacolo

Uno spettacolo è un solo file `.zip`. Chi ha il file ha lo spettacolo: testo, cue, inchiostro, tavole, impostazioni e tutta la cronologia.

## Sapere dov'è lo spettacolo

Guarda accanto al titolo.

| Dice | Lo spettacolo è |
|---|---|
| **Salvato** e un'ora | Nel suo file su disco, aggiornato |
| **Da salvare**, **Salvataggio…** | Sta per esserlo |
| **Non su disco** | Solo dentro questo browser |
| **Salvataggio fallito** | Non salvato; un messaggio dice perché |

Uno spettacolo che sta solo nel browser si perde se i dati del browser vengono cancellati. Mettilo in un file: **☰** → **Salva come file spettacolo…**.

## Farne una copia di sicurezza

Copia lo `.zip`. È una copia completa.

Un'abitudine che non costa niente: dopo ogni prova, salvata la revisione, copia il file in un secondo posto (una chiavetta, una cartella sincronizzata) con la data nel nome.

La cronologia dentro il file protegge da una modifica sbagliata. Non protegge dalla perdita del file. Per quello c'è solo una copia.

## Spostarlo su un altro computer

1. Copia lo `.zip` sull'altro computer.
2. Apri lì `promptbook.html` (la stessa versione o una più recente) e premi **Apri il file dello spettacolo…**.

Modalità notte, zoom e interruttori di vista non viaggiano: appartengono a ciascun browser.

## Tenerlo in una cartella sincronizzata

Un file spettacolo può stare in una cartella che Dropbox, OneDrive o simili tengono allineata. Allora:

- **Una sola persona lo tiene aperto per modificarlo.** Le modifiche di due persone non vengono fuse.
- Se il file viene sostituito da fuori mentre lo hai aperto e non hai niente di non salvato, viene ricaricato. Se hai modifiche non salvate, una fascia chiede: **Tieni la mia** o **Carica quella versione**. Niente viene sovrascritto finché non rispondi.

## Dare il testo all'autore

L'autore non ha bisogno dello strumento.

- **Per leggere:** stampa «Solo pagine del copione» in PDF, o manda un file per gli attori.
- **Per modificare:** **☰** → **Modifica tutto il testo…**, copia tutto, mandalo come file di testo. Come riprenderlo: [Accogliere una riscrittura](04-take-in-a-rewrite.md).

Il copione sta anche dentro lo zip, come `script.md`: qualunque programma per gli zip lo tira fuori e qualunque editor di testo lo legge.

## Dare a qualcuno tutto lo spettacolo

Manda lo `.zip`. Lo apre con `promptbook.html`. Mettetevi d'accordo su chi tiene la penna: due copie modificate insieme diventano due spettacoli.

## Da un browser che non può salvare file

In un browser diverso da Chrome o Edge lo spettacolo resta dentro il browser. Per tirarlo fuori: **Esporta backup** (nella fascia, o nel Menu) scrive un solo file `.promptbook.json` con tutto tranne la cronologia. In Chrome o Edge: **Importa un file di backup…** nella schermata iniziale, poi **Salva come file spettacolo…**.

## Se qualcosa non va

- **«Questo spettacolo viene da una versione più recente.»** Il file è stato salvato l'ultima volta da un `promptbook.html` più recente di quello che hai aperto. È aperto, ma procurati lo strumento più recente prima di cambiare molto.
- **«Questo file spettacolo ha parti illeggibili.»** Lo spettacolo si apre senza, e non viene salvato niente finché non scegli. Se hai una copia recente, scegli **Chiudi lo spettacolo** e apri la copia. Altrimenti **Continua senza**: la parte danneggiata resta da parte dentro il file.
- **«file zip danneggiato».** Il file è troncato o rotto; non è stato toccato. Usa la tua copia.
- **Il file sta diventando grande.** Ogni revisione lo fa crescere, le immagini soprattutto. È sempre un solo file; copialo meno spesso sui supporti lenti.
