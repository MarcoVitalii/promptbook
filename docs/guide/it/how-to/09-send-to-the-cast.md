# Come inviare il copione e le note agli attori

Dai agli attori il testo aggiornato sui loro telefoni, con le note di regia sulle battute a cui si riferiscono, e rifallo dopo ogni prova senza che nessuno perda le proprie note.

## Una volta: fai un reparto per le note

1. **☰** → **Invia agli attori…**
2. Se dice che nessun reparto è segnato «Attori», premi **Aggiungi un reparto «Note»**.

Oppure, per sceglierne il nome: **☰** → **Impostazioni…**, **+ Reparto**, dagli una sigla (`REG`) e un nome (`Regia`), e spunta **Attori**. Il nome è ciò che gli attori leggono come autore della nota. Puoi averne più d'uno: Regia, Coreografia, Direzione di scena.

## Scrivere una nota per un attore

1. **Tocca una parola** della battuta a cui la nota si riferisce.
2. Premi il reparto delle note (**NOTE**).
3. Di' per chi è. Il campo dice «Per: vuoto =» e il nome di chi dice la battuta:
   - lascialo **vuoto** per quel personaggio;
   - premi **Tutti**, o i nomi di altri personaggi, per mandarla altrove.
4. Scrivi la nota nel campo «Nota per gli attori». Invio.

Una nota su un'azione o su un titolo, con «Per» vuoto, va a tutti.

La nota appartiene a tutta la battuta, qualunque parola tu abbia toccato. Si vede nel tuo margine come un cue, è elencata in **Rivedi** → «Note per gli attori», e resta fuori dai fogli dei cue.

Durante una prova, metti le note man mano che il regista le dà. Alla fine le hai tutte, ognuna sulla sua battuta.

## Mandare il file

1. **☰** → **Invia agli attori…**. Il riquadro dice quante note aspettano e per chi. Confrontalo con ciò che ti aspetti.
2. Premi **Salva il file per gli attori (.html)**. Prende il nome dello spettacolo, `…-cast.html`.
3. Manda quel solo file alla compagnia come mandi tutto il resto: il gruppo di chat, la posta, una cartella condivisa.
4. **Salva una revisione** con il suo nome («File per gli attori, 12 ottobre»). Il file per gli attori non si registra da solo nella cronologia; è così che saprai che cosa ha la compagnia.

Che cosa parte: il testo senza cue, commenti e appunti «da fare», e le note dei reparti segnati «Attori». Che cosa resta: tutto il resto.

## Che cosa dire agli attori, la prima volta

> Apri il file nel browser del telefono. Premi **La mia parte** e spunta ogni nome sotto cui parli, anche i gruppi di cui fai parte. **Nascondi le mie battute** copre le tue battute per provare a memoria; toccane una per vederla. Tocca una battuta qualsiasi per aggiungere una tua nota. Quando mando un nuovo file, aprilo allo stesso modo: le tue note restano.

## Rimandare dopo le modifiche

Fai esattamente lo stesso: **Invia agli attori…** → **Salva il file per gli attori (.html)**, e mandalo.

Quando un attore apre il nuovo file, comincia da **Novità**: le note da leggere, le battute cambiate e quante sono sue, e le sue note che stanno su una battuta cambiata. La sua parte, le sue note e ciò che aveva letto restano.

Le note già sistemate: eliminale nel copione (tocca l'etichetta, **Elimina**) prima di mandare, e nel prossimo file non ci sono. Le note che lasci vengono rimandate, e restano segnate come lette per chi le aveva lette.

## Provalo una volta con una persona

Prima che tutta la compagnia ci faccia affidamento, manda il file a un attore e chiedigli di: aprirlo, spuntare la sua parte, scrivere una nota, chiudere tutto, riaprire il file. Se la parte e la nota ci sono ancora, il suo telefono le conserva.

Se no (alcune app di posta e di chat aprono gli allegati in un visualizzatore che non ricorda niente), chiedigli di salvare il file sul telefono e aprirlo dal browser. Non è ancora stato provato su telefoni veri; considera il primo invio come la prova.

## Se qualcosa non va

- **Un attore ha cambiato telefono, o le sue note sono sparite.** Sul vecchio dispositivo: il menu → **Esporta le mie note**. Sul nuovo: apri il file per gli attori, poi apri quell'esportazione dal menu (**Importa le mie note…**).
- **«Questo file è più vecchio di quello che hai.»** Ha aperto il file della settimana scorsa. Non è cambiato niente; deve aprire il più recente.
- **Un attore vede note per altri.** Sotto «Tutti», sì: un solo file va a tutti. Non scrivere in una nota per gli attori ciò che deve leggere una persona sola.
- **Una nota è andata alla persona sbagliata.** Un «Per» vuoto segue chi dice la battuta. Se la nota è stata trascinata sulla battuta di un altro, ora è sua. Aprila e indica il personaggio.
- **Qualcuno tiene già il lettore e vuole solo lo spettacolo.** **Solo testo e note (.cast.json)** è questo: più piccolo, si apre dal menu del lettore.
